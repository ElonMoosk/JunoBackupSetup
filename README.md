# Juno Save Auto Backup

**Juno: New Origins / SimpleRockets 2 存档自动备份工具（Windows）**  
**Scheduled save backup utility for Juno: New Origins / SimpleRockets 2 (Windows)**

[下载最新版 / Download latest release](https://github.com/ElonMoosk/JunoBackupSetup/releases/latest)

## 功能 / Features

- 定时完整备份 `UserData`，默认每 30 分钟，可调 1–60 分钟。  
  Scheduled full backups of `UserData`, 30 minutes by default, adjustable 1–60 minutes.
- 最多保留 42 个版本，可调 1–42；达到上限后确认再轮换。  
  Up to 42 versions, adjustable 1–42; confirmation before rotating the oldest.
- 支持 16 种界面语言。  
  16 UI languages.
- 朱诺风格深色界面。  
  Juno-style dark UI.
- 存档、模组、截图、Vizzy 程序目录快捷按钮。  
  Quick access to saves, mods, screenshots and Vizzy programs.
- 一键安装，无需管理员权限；独立卸载，保留备份。  
  One-click install without admin rights; standalone uninstaller keeps backups.

## 默认路径 / Default paths

- 源目录 / Source: `%USERPROFILE%\AppData\LocalLow\Jundroo\SimpleRockets 2\UserData`
- 备份目录 / Destination: `D:\JunoSaveBackup`

## 安装 / Install

1. 下载 `JunoBackupSetup.exe`。
2. 双击安装。默认安装到 `D:\JunoBackupTool`；没有 D: 盘时安装到 `%LOCALAPPDATA%\Programs\Juno Save Auto Backup`。
3. 启动后自动开始定时备份。

## 卸载 / Uninstall

- 主窗口底部红色“卸载”按钮；
- 或开始菜单 → `Uninstall Juno Save Auto Backup`；
- 备份目录不会被删除。

## 说明 / Notes

  Unofficial tool, not affiliated with Jundroo.
- 备份前请确保目标盘有足够空间。
